# 🛒 پنل فروش Marketplace

> [!info] بخش ۸.۳ — ۷ قابلیت اصلی + قابلیت‌های مدرس

## تعریف
پنل برای فروش مستقل توسط مدرس (LMS as a Marketplace). مدرس دوره تولید، پلتفرم کنترل کیفیت می‌کند، دوره قیمت‌گذاری و فروخته می‌شود.

## فرآیند کلی

```mermaid
flowchart TB
    T[مدرس] -->|تولید محتوا| P[پلتفرم]
    P -->|کنترل کیفیت| QC{تأیید؟}
    QC -->|بله| PR[قیمت‌گذاری]
    QC -->|خیر| REJ[رد/اصلاح]
    PR --> S[فروش]
    S --> REV[تسویه حساب]
    REV -->|۷۰٪| T
    REV -->|۳۰٪| P

    style T fill:#1B7D46,color:#FFFFFF
    style P fill:#1B2A4A,color:#FFFFFF
    style S fill:#8E44AD,color:#FFFFFF
```

## ۷ قابلیت اصلی

| # | قابلیت | توضیح |
|---|---|---|
| ۱ | **تعریف درصد کمیسیون طرفین** | قابل تنظیم (مثلاً ۷۰/۳۰) |
| ۲ | **تسویه حساب با مدرس** | خودکار یا دستی |
| ۳ | **گزارشات فروش** | به تفکیک سال، ماه، نام مدرس، عنوان دوره |
| ۴ | **کوپن تخفیف** | ایجاد و مدیریت |
| ۵ | **امتیازدهی و نظرات کاربران** | سیستم بازخورد و review |
| ۶ | **سبد خرید مشتری** | مدیریت سبد و checkout |
| ۷ | **پرداخت آنلاین** | اتصال به درگاه پرداخت |

## قابلیت‌های مدرس

> [!important] چون مدرس در فرآیند پشتیبانی هم نقش دارد، سیستم ارزیابی برای مدرس مهم است.

```mermaid
mindmap
  root((قابلیت‌های مدرس))
    مدیریت دوره
      تولید محتوا
      بارگذاری
      ویرایش
      آپدیت بر اساس بازخورد
    جلسات Live
      پرسش و پاسخ
      رایگان
      پولی
    پشتیبانی
      تیکتینگ
      انجمن داخلی
      پاسخ به دانشجویان
```

## سناریوهای درآمدی

| سناریو | قیمت دوره | سهم مدرس | سهم پلتفرم |
|---|---|---|---|
| دوره ارزان | ۱۰۰٬۰۰۰ تومان | ۷۰٬۰۰۰ | ۳۰٬۰۰۰ |
| دوره متوسط | ۵۰۰٬۰۰۰ تومان | ۳۵۰٬۰۰۰ | ۱۵۰٬۰۰۰ |
| دوره گران | ۲٬۰۰۰٬۰۰۰ تومان | ۱٬۴۰۰٬۰۰۰ | ۶۰۰٬۰۰۰ |

## فلوچانت خرید کاربر

```mermaid
sequenceDiagram
    actor User as کاربر
    participant LMS as LMS
    participant Cart as سبد خرید
    participant Pay as درگاه پرداخت
    participant Inst as مدرس
    participant Settle as تسویه

    User->>LMS: مرور دوره‌ها
    LMS->>User: نمایش دوره‌ها + امتیاز + نظرات
    User->>Cart: افزودن به سبد
    User->>Cart: اعمال کوپن تخفیف
    Cart->>Pay: هدایت به درگاه
    Pay->>Pay: پرداخت موفق
    Pay->>LMS: تأیید پرداخت
    LMS->>User: دسترسی به دوره
    LMS->>Settle: ثبت تراکنش
    Settle->>Inst: ۷۰٪ به مدرس
    Settle->>LMS: ۳۰٪ به پلتفرم
```
