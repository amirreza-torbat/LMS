## ساختار محتوا

```mermaid
flowchart TB
    Course[📚 دوره Course]
    Course --> Module[📦 ماژول]
    Module --> Lesson[📖 درس]
    Lesson --> Content[🎬 محتوا]

    Content --> Types{نوع محتوا}
    Types --> Video[🎥 ویدیو]
    Types --> Audio[🎵 صوت/پادکست]
    Types --> PDF[📄 PDF تعاملی]
    Types --> Text[📝 متن]
    Types --> VR[🥽 VR]
    Types --> SCORM[💿 SCORM]
    Types --> H5P[🎯 H5P]

    style Course fill:#1B2A4A,color:#FFFFFF
    style Types fill:#1B7D46,color:#FFFFFF
```

## استانداردهای پشتیبانی‌شده

- **SCORM 1.2** و **SCORM 2004 4th Edition**
- **H5P** — محتوای تعاملی HTML5
- **xAPI (Tin Can)** — ردیابی یادگیری
- **HTML5** — پشتیبانی پایه
