## ۱. معماری Gamification Engine

```mermaid
flowchart TB
    User[👤 کاربر] --> Action[📝 انجام فعالیت]

    subgraph Detect[تشخیص رویداد]
        Action --> ED[Event Detector]
        ED --> Valid{معتبر؟}
        Valid -->|بله| PE[Point Engine]
        Valid -->|خیر| AC[Anti-Cheat]
    end

    subgraph Process[پردازش]
        PE --> Calc[محاسبه امتیاز]
        Calc --> BS{آستانه Badge؟}
        Calc --> LB{رتبه تغییر؟}
        Calc --> LV{سطح تغییر؟}
    end

    subgraph Notify[اعلان]
        BS -->|بله| BA[اعطای Badge]
        LB -->|بله| LR[به‌روزرسانی Leaderboard]
        LV -->|بله| LU[Level Up]
        BA --> NN[اعلان هوشمند]
        LR --> NN
        LU --> NN
    end

    NN --> User

    style Detect fill:#1B2A4A,color:#FFFFFF
    style Process fill:#1B7D46,color:#FFFFFF
    style Notify fill:#8E44AD,color:#FFFFFF
```

## ۳. فرآیند امتیازدهی

```mermaid
sequenceDiagram
    actor User as کاربر
    participant LMS as LMS
    participant PE as Point Engine
    participant BS as Badge System
    participant LV as Level System
    participant LB as Leaderboard
    participant NN as Notifications

    User->>LMS: شرکت در بحث (forum_post)
    LMS->>PE: ثبت فعالیت
    PE->>PE: محاسبه امتیاز (+4)
    PE->>PE: به‌روزرسانی امتیاز کل
    PE->>BS: بررسی آستانه Badge
    PE->>LV: بررسی ارتقای سطح
    PE->>LB: به‌روزرسانی رتبه

    BS->>BS: رسیدن به آستانه جدید
    BS->>User: اعطای Badge 🏆

    LV->>LV: رسیدن به آستانه سطح
    LV->>User: Level Up! 📈

    LB->>LB: محاسبه رتبه جدید
    LB->>User: نمایش رتبه در لیدربورد

    NN->>User: اعلان تبریک 🎉
```
