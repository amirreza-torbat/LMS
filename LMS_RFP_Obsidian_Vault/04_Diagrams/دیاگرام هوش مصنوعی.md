```mermaid
flowchart TB
```

## ۳. فلوچانت چت‌بات آموزشی (RAG)

```mermaid
sequenceDiagram
    actor Student as دانشجو
    participant UI as Chatbot UI
    participant RAG as RAG System
    participant VDB as Vector DB
    participant LLM as LLM
    participant Sent as Sentiment Analysis

    Student->>UI: سؤال
    UI->>RAG: ارسال سؤال
    RAG->>VDB: جستجوی محتوای مرتبط
    VDB->>RAG: برگرداندن مستندات
    RAG->>LLM: تولید پاسخ با context
    LLM->>Sent: تحلیل احساسات پاسخ
    Sent->>UI: پاسخ + سطح احساس

    alt ناامیدی تشخیص داده شد
        UI->>Student: پاسخ + پیام تشویقی
    else خستگی تشخیص داده شد
        UI->>Student: پاسخ + پیشنهاد استراحت
    else عادی
        UI->>Student: پاسخ عادی
    end
```

## ۵. زیرساخت LLM + RAG

```mermaid
flowchart TB
    subgraph Data[منابع داده]
        CD[محتوای دوره]
        DOC[اسناد]
        FAQ[پرسش‌های متداول]
    end

    subgraph Process[پردازش]
        EMB[Embedding]
        VDB[(Vector DB)]
    end

    subgraph Runtime[زمان اجرا]
        Q[سؤال کاربر]
        SEARCH[جستجوی معنایی]

        LLM[LLM]

    EMB --> VDB

    Q --> SEARCH
    VDB --> SEARCH
    SEARCH --> CTX
    CTX --> LLM
    Q --> LLM
    LLM --> ANS
```
