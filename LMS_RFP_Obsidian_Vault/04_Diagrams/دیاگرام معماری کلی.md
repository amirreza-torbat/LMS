## ۴. معماری Event-Driven

```mermaid
sequenceDiagram
    actor User as کاربر
    participant UI as UI Layer
    participant API as API Gateway
    participant Core as Core Engine
    participant Bus as Event Bus
    participant Reporter as Enterprise Reporter
    participant Grader as Academic Grader
    participant AI as AI Module
    participant Gamif as Gamification

    User->>UI: اتمام دوره
    UI->>API: POST /course/complete
    API->>Core: process
    Core->>Core: ثبت تکمیل
    Core->>Bus: publish(course_completed)
    Bus->>Reporter: notify (Enterprise)
    Bus->>Grader: notify (Academic)
    Bus->>AI: notify (AI)
    Bus->>Gamif: notify (Gamification)

    Reporter->>Reporter: تولید گزارش پیشرفت
    Grader->>Grader: ثبت نمره نهایی
    AI->>AI: تحلیل الگوی یادگیری
    Gamif->>Gamif: اعطای Badge/Points
```

## ۷. فرآیند یکپارچگی HRIS

```mermaid
sequenceDiagram
    participant HR as سیستم HR سازمان
    participant API as LMS API
    participant DB as LMS Database
    participant User as کاربر

    Note over HR,User: کارمند جدید
    HR->>API: POST /users/sync {employee_id, name, dept}
    API->>DB: INSERT user
    API->>User: ارسال اطلاعات ورود (SMS)
    User->>API: Login اولین بار
    API->>DB: ثبت اولین نشست

    Note over HR,User: اخراج کارمند
    HR->>API: PATCH /users/{id} {status: terminated}
    API->>DB: UPDATE user SET active=false
    API->>User: اطلاع مسدودسازی
```

## ۸. فرآیند یکپارچگی SIS

```mermaid
sequenceDiagram
    participant SIS as SIS (گلستان)
    participant API as LMS API
    participant DB as LMS Database
    participant Student as دانشجو
    participant Prof as استاد

    Note over SIS,Prof: شروع ترم
    SIS->>API: POST /sync/students {list}
    API->>DB: INSERT/UPDATE students
    SIS->>API: POST /sync/courses {list}
    API->>DB: INSERT/UPDATE courses

    Note over SIS,Prof: انتخاب واحد
    Student->>API: POST /enroll {course_id}
    API->>API: بررسی پیش‌نیاز
    API->>DB: INSERT enrollment

    Note over SIS,Prof: پایان ترم
    Prof->>API: POST /grades {course_id, grades[]}
    API->>DB: INSERT grades
    API->>SIS: POST /sync/grades {export}
    SIS->>SIS: ثبت در کارنامه رسمی
```

## ۹. معماری Gamification Engine

```mermaid
flowchart TB
    User[👤 کاربر] --> Action[📝 انجام فعالیت]

    subgraph Detect[تشخیص رویداد]
        Action --> ED[Event Detector]
        ED --> Valid{معتبر؟}
        Valid -->|بله| PE[Point Engine]
        Valid -->|خیر| AC[Anti-Cheat]
    end

    subgraph Process[پردازش]
        PE --> Calc[محاسبه امتیاز]
        Calc --> BS{آستانه Badge؟}
        Calc --> LB{رتبه تغییر؟}
        Calc --> LV{سطح تغییر؟}
    end

    subgraph Notify[اعلان]
        BS -->|بله| BA[اعطای Badge]
        LB -->|بله| LR[به‌روزرسانی Leaderboard]
        LV -->|بله| LU[Level Up]
        BA --> NN[اعلان هوشمند]
        LR --> NN
        LU --> NN
    end

    NN --> User

    style Detect fill:#1B2A4A,color:#FFFFFF
    style Process fill:#1B7D46,color:#FFFFFF
    style Notify fill:#8E44AD,color:#FFFFFF
```
